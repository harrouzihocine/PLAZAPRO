# frontend/ — Vue 3 SPA

This folder holds the Vue 3 single‑page app (Vite). It is currently empty — the app is generated by the
Node toolchain inside the `node` container.

## Install (run from repo root, with the stack up)

```bash
docker compose exec node sh -c "npm create vite@latest . -- --template vue"
docker compose exec node npm install
docker compose exec node npm install vue-router@4 pinia axios
docker compose exec node npm install -D tailwindcss@3 postcss autoprefixer
docker compose exec node npx tailwindcss init -p
```

Then follow [`../docs/phase-0-foundations/08-vue-install.md`](../docs/phase-0-foundations/08-vue-install.md)
and [`09-theming-and-appshell.md`](../docs/phase-0-foundations/09-theming-and-appshell.md) to:

- create the feature‑based folders (`src/features/*`, `components/base`, `composables`, `layouts`, `router`);
- add `vite.config.js` with the `/api` + `/sanctum` proxy to `nginx`;
- add the `useApi` wrapper (**Sanctum SPA cookie auth**, `withCredentials` + `withXSRFToken`, no token header);
- add `tokens.css` (gold/white + gold/black), wire Tailwind to the CSS variables, and build `useTheme`
    - the responsive `AppShell` (sidebar on desktop, bottom nav on mobile).

## Dev URLs

- Vite dev server (HMR): http://localhost:5173
- App via nginx (prod‑like): http://localhost:8080
